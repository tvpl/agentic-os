# SDD artifact templates

## spec.md
```markdown
# Spec: <feature>
## Story
As a <user>, I want <capability> so that <outcome>.
## In scope / Out of scope
## Acceptance criteria
- [ ] Given … when … then …   (each one testable)
## Open questions
```

## plan.md
```markdown
# Plan: <feature>
## Approach (and alternatives considered)
## Touched modules/files
- path — why
## Data / schema changes
## Risks & mitigations
```

## tasks.md
```markdown
# Tasks: <feature>
1. [ ] <task> — files: … — done when: …
2. [ ] …          (mark [P] when parallelizable)
```
