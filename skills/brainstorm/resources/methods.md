# Brainstorm lenses

Use at least four:

1. **Inversion** — how would we guarantee failure? Reverse each answer.
2. **Analogy** — how do other industries solve the same shape of problem?
3. **Constraint removal** — what if money/time/tech were unlimited? Then re-add constraints.
4. **Constraint extreme** — what if we had 1 day / $0 / one user?
5. **Combination** — merge two existing things the user already has.
6. **User journey** — walk the day of the target user; attack each friction point.
7. **Second-order** — what becomes possible only after an obvious idea ships?

## Converge scoring
Impact (1–5) × Feasibility (1–5); note the score next to each idea.
Tie-break by "energy": which idea would the user actually start this week?
