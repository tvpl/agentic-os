   force matters for a retry is a run whose stored `cwd` is the folder, for example an objective step's run. My probe

   as written, and F6 shows the retry case does bite on the folder hand-off.

   (`core/src/engine.ts:472-475`) uses it. My probe: `{memory:{embeddings:{endpoint:B}}}` through it keeps `apiKeyEnv`
   `OPENAI_API_KEY` with endpoint B. That is the leak door 13 closes on the route, reachable only from an in-process
   program of the owner. No HTTP, CLI or MCP caller passes `memory` to it: the callers are `autostart`,
   `favoriteSkills`, `defaultProvider`, `bindAddress` and the contexts' function patches. It does not fail this
   feature, but it is worth its own fix.
3. **C51's "settings read" is the store's read** (`w.ctx.settings()`, `tests/organize.sync.test.ts:256`), not `GET
/api/settings`. P7 shows both agree, and also the PUT's response.
