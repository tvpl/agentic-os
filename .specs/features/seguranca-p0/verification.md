- Enumeração de rotas: sem credencial, rota existente responde 401 e rota inexistente 404 (antes, todo `/api/*` cru respondia 401). O impacto é baixo, porque a lista de rotas já é pública no código-fonte.
- O fallback da SPA ainda decide pelo caminho cru (`server.ts:326-331`): `GET /%61pi/nope` e `GET /API/settings` recebem a página HTML. Ela só leva o token quando socket e Host são loopback, então os dados da API não vazam.
- A injeção do token confia no socket: um proxy reverso local (ex.: `tailscale serve`, Caddy) que reescreva o Host para `localhost` entregaria o token a um cliente remoto. Isso fica fora do modelo da feature, mas vale uma linha na `docs/security.md`.
- O `Map` de credenciais de broker só esquece uma credencial quando ela é reapresentada depois do fim da execução (`context.ts:333-340`). Fica uma entrada por execução de escrita durante a vida do processo, sem efeito de segurança.
