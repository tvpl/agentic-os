## Confirmed (attack list)

- **Notes security**: a device token holding `monitor, content, run, approve` gets `403 owner_only` on `POST` and `PUT`, a run credential `403 forbidden`, a `content` device reads (`memory.notes.test.ts:396,429,441`); concurrent saves: 6 parallel `PUT` with the same `baseVersion` give exactly one `200` and five `409` (probe P-concurrent); symlink and hard link of `config/token` (read and write) `403 forbidden_path`, token bytes unchanged (probe + C12); `..` and absolute outside paths `403`; `memory/JOURNAL/…` and `Router.MD` refused as generated; 1 MiB exactly written, +1 byte `413`; 2 000 001 characters `400`; 5 MiB body `413 payload_too_large`.
- **Guarded replace**: same-millisecond edits are caught because the version is the hash (C8 `memory.notes.test.ts:232-240`); no truncate before the check (C57 `security-writes.test.ts:1293-1300`, mutant M1 killed by C57, C7, C8).
- **Worker**: `requestIndexPaths` + full + path requests while a pass runs: 4 passes for 9 callers, no leaked state, `isIndexing()` false after (Q2); cancel during the vectors phase against a loopback endpoint that never answers: `index_cancelled` in 44 ms, 50 files kept, lock free (Q3); a hard `terminate()` mid-pass then a pass: the recovery pass `related 2151`, the next `0` (Q4, and mutant M5b killed by C35); an exclusive restore lock during a pass is refused with `RestoreInProgressError` (Q5); the packaged service (`dist:quick`, sidecar mode) reports `indexing.mode: "worker"`, `semantic.backend: "sqlite-vec"`, `embedded: 24`, with `lib/indexWorker.mjs` and `lib/node_modules/sqlite-vec{,-linux-x64}` present.
- **Semantic, default off**: no vector, no `loadExtension`, no `fetch`, `mode=semantic` `409` (C43 `memory.semantic.test.ts:94-105`); the endpoint policy rejects credentials in the URL, `http` remote, `https` without `sendRemote`, `::ffff:127.0.0.1` and `localhost.` (not loopback, so refused), redirects (`redirect: "error"`), 8 MB cap, 30 s timeout, 16 per batch; private ranges over `https` + `sendRemote` are **allowed** (the push destination refuses them, this one does not; the text does not claim otherwise); unreadable settings read as off (C52).
- **Migrations 20/21**: `IF NOT EXISTS`, no row changed, pinned shapes with `toEqual`, user version 21 (`data.migration.test.ts:435-453,494-544`); `removeFile` deletes `note_links`/`file_vectors` of a removed id (`indexer.ts:797-798`); no other `DELETE FROM files` exists.
- **Pins amended**: `sdk.api-thin` C29 `AMENDMENTS` (seven entries for `device-scopes`, `times` for the one that matches two places) change only totals and the migration list; each still must match exactly `a.times ?? 1` times; none weakened. `api.contract`, `contracts.api`, `device-scopes`, `events.contract`, `api.openapi` diffs are totals only (127->132, 63->66, 22->24, 23->25, raised 49->60).
